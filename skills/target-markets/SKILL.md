# Hədəf bazar seçimi

## Addımlar
1. **Məhsulu və məhdudiyyətləri dəqiqləşdir:** məhsul və ya xidmət (ticarət üçün HS kodu), büdcə, satış modeli (ixrac, onlayn, yerli tərəfdaş, nümayəndəlik), istisna olunan ölkələr.
2. **Geniş siyahı (10–20 ölkə):** idxal həcmi və artımı (UN Comtrade), əhali və gəlir (Dünya Bankı), coğrafi və dil yaxınlığı, mövcud ticarət sazişləri.
3. **Süzgəc:** aşağıdakı meyarlar üzrə hər ölkə üçün mənbəli rəqəm topla. Rəqəm tapılmayan xananı boş saxla, təxmin yazma.
4. **Bal:** hər meyarı 1–5 şkalasına çevir, çəkilərlə cəmlə. Çəkiləri istifadəçidən soruş və ya defoltu göstər. Hesablamanı kodla apar.
5. **Qısa siyahı (3–5 ölkə):** hər biri üçün dərin təhlil: rəqiblər (`competitor-watch`), tənzimləmə (`research-types` hüquq sətri), giriş yolu və təxmini xərc.
6. **Həssaslıq:** çəkiləri dəyişəndə sıralama dəyişirmi. Dəyişirsə, bunu açıq yaz.

## Meyarlar

| Meyar | Göstərici | Mənbə |
|---|---|---|
| Bazar həcmi | məhsul üzrə idxal və ya istehlak, əhali, adambaşına gəlir | UN Comtrade, Dünya Bankı, milli statistika |
| Artım | son 3–5 ildə idxal və ya satış artımı | UN Comtrade, milli statistika |
| Rəqabət | əsas təchizatçı ölkələr və payları, yerli oyunçular | UN Comtrade, şirkət saytları |
| Giriş maneələri | gömrük tarifi, qeyri-tarif tədbirləri, sertifikat, lisenziya | WTO, WITS, milli tənzimləyici |
| Logistika | məsafə, daşıma yolu, müddət, xərc | daşıma şirkətləri, LPI (Dünya Bankı) |
| Ödəniş və valyuta | valyuta məhdudiyyəti, məzənnə dəyişkənliyi, ödəniş üsulları | mərkəzi bank, IMF |
| Biznes mühiti | şirkət açmaq, vergi, hüquqi müdafiə | milli qanunvericilik, OECD, Dünya Bankı |
| Risk | siyasi və iqtisadi sabitlik, sanksiyalar | sanksiya siyahıları, IMF |
| Uyğunluq | dil, mədəniyyət, istehlak vərdişləri, kanal quruluşu | sorğular, e-ticarət saytları, Google Trends |

## Qaydalar
- Bütün ölkələr üçün eyni il, eyni valyuta, eyni tərif. Ölkələr arası müqayisədə beynəlxalq mənbəni, dərin təhlildə milli mənbəni üstün tut.
- Bal cədvəlini və xam rəqəmləri ayrı göstər. Bal mühakimədir, hesabatda təhlil bölməsinə aiddir.
- Sanksiya və ixrac nəzarəti məsələlərində yekun söz hüquqşünasındır.
